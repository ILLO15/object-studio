# Object Studio

제품 3D 모델(STL·OBJ·GLB·3MF)을 불러와 가상 스튜디오에서 제품 사진과 턴테이블 영상을 만드는 브라우저 앱입니다. 설치나 서버 없이 정적 파일만으로 동작합니다.

## 주요 기능

- 홀 5종(호리존, 원형 호리존, 코너, 원형 단상, 무한 바닥), 배경 톤, 조명 프리셋과 방향·높이·노출
- 고정 앵글 버튼, 오브젝트 좌우·자유 회전, 렌즈(24–135mm), 화면비, 출력 범위 표시
- 전체 및 부위별 재질, 텍스처 이미지 적용
- 접지 그림자 강도·부드러움
- PNG 촬영(최대 4K, 투명 배경), 저장한 구도 일괄 출력(ZIP), 턴테이블 녹화(MP4 또는 WebM)
- 실행 취소·다시 실행, 자동 복구, 연출 프리셋, 템플릿(JSON) 내보내기·불러오기
- 파일 단위 지정(mm, cm, m, inch)

## 사용 방법

### 웹 주소로 열기

GitHub Pages 등에 올린 주소를 브라우저(Chrome, Edge, Safari 최신판)로 엽니다. 처음 연 뒤에는 오프라인에서도 열립니다. 주소창의 설치 버튼을 누르면 바탕화면 앱처럼 쓸 수 있습니다.

### 내 컴퓨터에서 바로 열기

`index.html`을 더블클릭하면 브라우저 보안 정책 때문에 동작하지 않습니다. 대신 다음 파일을 실행하세요. 두 방법 모두 Python이 설치되어 있어야 합니다.

- Windows: `start-windows.bat`
- macOS: `start-mac.command` (처음 한 번은 우클릭 후 열기)

## 배포 (GitHub Pages)

저장소의 Settings → Pages에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다. 무료 계정은 공개 저장소에서만 Pages를 쓸 수 있습니다.

`index.html`이나 다른 파일을 고친 뒤 배포할 때는 `sw.js`의 `VERSION` 값을 올려 주세요. 그래야 사용자 브라우저가 새 버전을 받습니다.

## 저장 위치에 대한 안내

자동 복구 데이터, 사용자 프리셋, 마지막으로 불러온 모델은 각 브라우저 안에만 저장됩니다. 다른 컴퓨터로 옮기려면 `템플릿으로 내보내기`로 JSON 파일을 받아 옮긴 뒤 불러오세요. 템플릿에는 모델 파일이 들어가지 않습니다.
